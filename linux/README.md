# Amazon Linux 2023 Operations Track

**Phase 2 — Not Started.** Practice practical Linux administration as it supports AWS Cloud Support/CloudOps, not a separate RHCSA specialization.

## Practice sequence

1. Filesystem navigation, standard streams, basic shell commands and finding files.
2. Users/groups, file modes, sudo policy and safe account changes.
3. DNF package updates, basic service installation and configuration.
4. Processes, `systemctl`, `journalctl`, service restarts and boot behavior.
5. IPv4 routes, DNS, listeners with `ss`, curl health checks and firewall model.
6. SSM session troubleshooting and instance profile permissions.
7. Evidence capture, rollback and a concise operations runbook.

**Target ticket:** The web service returns 503 behind ALB. Examine target health, `systemctl status`, `journalctl -u`, instance listeners, SGs and app dependency health; record actual command outputs and fix.

Follow least privilege, avoid publicly exposed SSH, and redact host/account details in screenshots. Do not mark tasks complete until performed and verified.
