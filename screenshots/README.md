# Apex Screenshot and Evidence Policy

**No Apex deployment screenshots have been captured or fabricated.**

Add screenshots only from work actually performed, label them with a real date, phase, service, and verified result, and describe what they prove (and what they do not). Crop or redact AWS account numbers, user IDs, access keys, secret values, internal/private IPs where sensitive, terminal tokens, hostnames and private customer data. Prefer sanitized CLI output or text tables when easier to reproduce. Do not upload Terraform state, secret-bearing logs, or unrelated console information.

Example future naming convention: `phase-02-ssm-session-verified-YYYYMMDD.png`. A filename is not evidence by itself.
