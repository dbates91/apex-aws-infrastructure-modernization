# Architecture Decision Records (ADRs)

Record meaningful design choices with an explicit status, alternatives, rejected options, cost/security impact, and evidence.

Current candidate decisions (all **Proposed**): one NAT versus per-AZ NAT, NAT versus SSM VPC endpoints, short-lived RDS lab versus simulated DB dependency, EC2 ASG versus ECS/Fargate, Terraform local state learning versus secure remote backend.

Use [ADR template](ADR_TEMPLATE.md). No decision is presented as implemented or tested.
